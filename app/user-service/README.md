# user-service

Сервис пользователей.

## Endpoint'ы

- `POST /users/register`
- `POST /users/login`
- `GET /users/:id`

## Примечания

- Сервис хранит пользователей в `PostgreSQL`.
- Используется как источник истины по данным пользователя для остальных микросервисов.
- Другие сервисы получают через него email и базовую информацию о пользователях.
